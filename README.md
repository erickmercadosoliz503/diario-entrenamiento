# Diario de entrenamiento

PWA para entrenadores y clientes (plan, sesiones, récords, revisiones con fotos).
HTML/CSS/JS sin build, Firebase Auth + Cloud Firestore, publicada con GitHub Pages.

- `index.html` – la app
- `firebase-config.js` – configuración pública de Firebase
- `firestore.rules` – reglas de seguridad (pegar en Firebase → Firestore → Reglas)
- `manifest.webmanifest`, `sw.js`, `icons/` – PWA instalable / base para la Play Store
- `privacidad.html`, `borrar-cuenta.html` – páginas exigidas por Google Play
